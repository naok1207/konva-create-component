# React-Konva Component Builder

React-Konvaコンポーネントを視覚的に作成し、Reactコンポーネントのコードを自動生成するWebアプリケーション。

## 特徴

- 🎨 ドラッグ&ドロップによる直感的な図形配置
- 📐 ピクセルグリッドによる正確な配置（デフォルト8px、任意指定可能）
- 💻 リアルタイムでReactコードを生成・表示
- 📋 生成されたコードをワンクリックでコピー
- 🔧 豊富な図形ツール（矩形、円、線、テキストなど）

## 技術スタック

- React + TypeScript
- Konva + react-konva
- Tailwind CSS
- Vite
